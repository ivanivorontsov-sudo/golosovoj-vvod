Голосовой ввод

Диктовка в любые поля сайтов · версия

Добро пожаловать!

  1. Нажмите «Разрешить микрофон» ниже (один раз).
  2. Выберите движок. В Vivaldi бесплатное Google-распознавание браузера отключено, поэтому установите офлайн-модель (45 МБ) или укажите ключ Google Cloud.
  3. Поставьте курсор в любое поле и нажмите Alt+Shift+V, кнопку 🎤 у поля или значок расширения.

1. Микрофон

Статус: проверяю…

Браузер спросит разрешение для расширения «Голосовой ввод». Это нужно сделать один раз — дальше ввод работает на всех сайтах без запросов. Если запрос не появился: значок замка/микрофона слева в адресной строке → Микрофон → Разрешить.

2. Движок распознавания

Как получить ключ (5 минут)
  1. Откройте console.cloud.google.com, создайте проект.
  2. Подключите платёжный аккаунт (Google требует его даже для бесплатных 60 минут).
  3. «APIs & Services» → «Library» → Cloud Speech-to-Text API → Enable.
  4. «Credentials» → «Create credentials» → «API key». В «API restrictions» оставьте только Speech-to-Text.
  5. Скопируйте ключ сюда. Он хранится только в этом браузере.

Фразы отправляются в Google после паузы в речи, поэтому текст появляется целыми фразами, без «живого» предпросмотра.

3. Язык диктовки

Быстро переключить: Alt+Shift+L, кнопка «RU/EN» в индикаторе записи или правый клик по значку расширения.

4. Горячие клавиши

Клавиша на страницах:
Работает всегда, когда курсор на веб-странице, — даже если Vivaldi перехватывает клавиши расширений. Нажмите кнопку и затем нужное сочетание (например Ctrl+Shift+Пробел).

Клавиша браузера: —

Как настроить в Vivaldi
  1. Откройте vivaldi://extensions → меню ☰ слева вверху → «Сочетания клавиш» (или адрес vivaldi://extensions/shortcuts).
  2. У «Голосовой ввод» назначьте «Начать / остановить голосовой ввод».
  3. Если сочетание не срабатывает, переключите область с «В Vivaldi» на «Глобально» — это известная особенность Vivaldi.
  4. Проверьте, что сочетание не занято самим Vivaldi: Настройки → Клавиатура.

Совет: Alt+Shift в Windows может переключать раскладку. Если мешает — выберите другое сочетание, например Ctrl+Shift+Пробел.

5. Поведение

Проверка

Нажмите в поле и скажите, например: «Привет запятая это проверка голосового ввода точка».

Конфиденциальность

Расширение ничего не собирает и не отправляет разработчику. Звук идёт только выбранному движку: Google (Web Speech или Cloud с вашим ключом) либо никуда (офлайн-режим). Настройки и ключ хранятся локально в браузере.

Офлайн-распознавание: Vosk (Apache 2.0), vosk-browser.
