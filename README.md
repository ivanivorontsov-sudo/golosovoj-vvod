# Голосовой ввод — расширение для Chrome и Vivaldi (Manifest V3)

Диктовка в **любое текстовое поле**: `input`, `textarea`, `contenteditable`, поля в iframe (в том числе с другого домена) и в shadow DOM, React-формы, редакторы Quill, ProseMirror (Tiptap), Lexical, Draft.js. Текст вставляется в позицию курсора через `execCommand('insertText')` / `InputEvent` (а для редакторов, которые этого не любят, — через синтетический `paste`), поэтому работают отмена (Ctrl+Z) и обработчики сайтов.

Без телеметрии, аналитики и сторонних серверов, кроме выбранного вами движка распознавания.

## Установка (Vivaldi / Chrome)

1. Распакуйте `golosovoj-vvod-1.0.0.zip` в постоянную папку, например `C:\Users\<вы>\Extensions\golosovoj-vvod`. Не удаляйте её после установки.
2. Откройте `vivaldi://extensions` (в Chrome: `chrome://extensions`).
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное»** и выберите папку, где лежит `manifest.json`.
5. Откроется страница настроек. Нажмите **«Разрешить микрофон»** и подтвердите доступ. Это нужно сделать один раз.
6. Для Vivaldi выберите движок (см. ниже): **офлайн Vosk** (бесплатно, кнопка «Скачать модель», около 45 МБ) или **Google Cloud** со своим API-ключом.

## Как запустить диктовку

| Способ | Действие |
|---|---|
| Горячая клавиша | **Alt+Shift+V**: старт и стоп в поле, где стоит курсор |
| Смена языка | **Alt+Shift+L**: RU ↔ EN |
| Остановка | **Esc**, повторное нажатие Alt+Shift+V, кнопка ✕ на индикаторе или фраза «стоп запись» |
| Кнопка 🎤 | появляется у поля при фокусе (её можно отключить в настройках) |
| Значок на панели | клик по значку расширения начинает диктовку в активном поле |
| Контекстное меню | правый клик по значку: язык и настройки |

Во время записи у поля виден индикатор: красная точка, уровень сигнала, движок, промежуточный текст, переключатель RU/EN и кнопка ✕. На значке расширения горит красный бейдж с языком (`RU`/`EN`). Запись останавливается сама после тишины (по умолчанию 15 с, настраивается, 0 = не останавливать).

**Особенности Vivaldi:** горячие клавиши расширения задаются в `vivaldi://extensions` → ☰ → «Сочетания клавиш». Если сочетание не срабатывает, выберите область действия «Глобально» или «В браузере». На всякий случай расширение само ловит Alt+Shift+V на странице, и это сочетание можно переназначить в настройках. В Windows Alt+Shift может переключать раскладку. Если мешает, отключите это сочетание в параметрах языка Windows или назначьте, например, Ctrl+Shift+Пробел.

## Движки распознавания

| Движок | Где работает | Что нужно |
|---|---|---|
| **Google Web Speech** (`webkitSpeechRecognition`) | Google Chrome | ничего, бесплатно |
| **Google Cloud Speech-to-Text** | Vivaldi, Chrome, Edge… | свой API-ключ (60 минут в месяц бесплатно, нужен платёжный аккаунт) |
| **Vosk офлайн** (WebAssembly) | везде, без интернета | один раз скачать модель (ru около 45 МБ, en около 40 МБ) |
| Google на устройстве (SODA, `processLocally`) | экспериментально | пакеты языков скачиваются из настроек |

Режим **«Авто»** (по умолчанию) сначала пробует Google Web Speech. Если браузер отвечает ошибкой `network`, как Vivaldi, расширение запоминает это и переходит на Google Cloud (если указан ключ), а затем на Vosk. Переход незаметен, начало фразы не теряется.

### Почему в Vivaldi не работает «обычный» Google

В Vivaldi `webkitSpeechRecognition` существует, но всегда завершается ошибкой `network`. Распознавание в Chrome идёт через закрытый сервер Google, доступ к которому есть только у Google Chrome. Chromium-браузеры вроде Vivaldi ключа к нему не получают, это подтверждают и chromium.org, и модераторы форума Vivaldi. Использовать ключ Chrome запрещено условиями Google. Поэтому для Vivaldi есть официальный Google Cloud Speech-to-Text (с вашим ключом) и офлайн Vosk.

### Как получить ключ Google Cloud

1. Откройте https://console.cloud.google.com/, создайте проект и привяжите платёжный аккаунт (первые 60 минут в месяц бесплатны).
2. «APIs & Services» → «Library» → **Cloud Speech-to-Text API** → Enable.
3. «APIs & Services» → «Credentials» → «Create credentials» → **API key**. В «API restrictions» разрешите только Cloud Speech-to-Text API.
4. Вставьте ключ в настройках расширения и нажмите «Проверить ключ». Ключ хранится только локально (`chrome.storage.local`).

## Голосовые команды (RU)

| Скажите | Получится |
|---|---|
| точка / запятая / двоеточие / точка с запятой | `.` `,` `:` `;` |
| вопросительный знак / восклицательный знак / многоточие | `?` `!` `…` |
| тире / дефис | `—` `-` |
| открыть / закрыть скобку | `(` `)` |
| открыть / закрыть кавычки | `«` `»` |
| новая строка / новый абзац | перенос строки / пустая строка |
| стоп запись, стоп, хватит | остановить диктовку |
| удали последнее, отмена | удалить последний вставленный фрагмент |

В английском режиме: *comma, period, question mark, new line, new paragraph, stop listening, scratch that…* Фразы вроде «точка зрения» и «точка отсчёта» командами не считаются. Первая буква предложения ставится заглавной автоматически. Если вы продолжаете начатое предложение, первое слово пишется со строчной (отключается в настройках).

## Разрешения и приватность

- `storage`: настройки; `offscreen`: скрытая страница, которая держит микрофон; `contextMenus`: меню значка.
- `host_permissions` есть только для `speech.googleapis.com` (Cloud) и `alphacephei.com` (скачивание моделей Vosk).
- Контент-скрипт работает на всех сайтах, иначе нельзя вставлять текст в любое поле. Он ничего не читает и не отправляет, пока вы не начнёте диктовку.
- Звук идёт только в выбранный движок: Google (Chrome или Cloud) либо остаётся на компьютере (Vosk).

## Ограничения

- Бесплатное распознавание Google в Vivaldi невозможно. Нужен ключ Cloud или Vosk.
- Точность Vosk (малая модель) ниже, чем у Google, и Vosk не расставляет знаки препинания сам. Пользуйтесь голосовыми командами.
- Поля паролей и числовые поля пропускаются намеренно. Закрытые (closed) shadow root недоступны расширениям.
- Google Docs и другие canvas-редакторы поддерживаются экспериментально (через вставку) и не тестировались.
- На страницах `vivaldi://`, `chrome://` и в Chrome Web Store расширения не работают (ограничение браузера).
- SODA (Google на устройстве) в Vivaldi запускается, но текст не возвращает.

## Разработка и тесты

```bash
npm install
npm run test:unit          # юнит-тесты обработки текста
npm run test:e2e           # сквозные тесты в Chromium (mock-распознаватель)
npm run test:e2e:vivaldi   # те же тесты в Vivaldi
npm run test:cloud         # Google Cloud через локальный mock-сервер + виртуальный микрофон
npm run test:audio -- /opt/vivaldi/vivaldi-bin auto   # реальная речь через PulseAudio
npm run pack               # dist/golosovoj-vvod-<версия>.zip
```

Структура: `extension/background.js` (service worker, сессии, маршрутизация по фреймам), `extension/offscreen/` (микрофон и движки), `extension/content/` (поиск поля, вставка, индикатор), `extension/common/` (настройки, обработка текста, хранилище моделей), `extension/lib/` (vosk-browser 0.0.8, адаптирован под CSP MV3 скриптом `tools/build-vosk.py`, лицензия Apache-2.0).
